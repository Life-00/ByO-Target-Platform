# 🚀 ByO Target Platform

> **Build your Own Target Platform**  
> 프로젝트 기간 동안 빠르게 실험하고, 명확하게 협업하기 위한 **ByO 팀의 메인 플랫폼 레포지토리**입니다.

---

## ✨ 프로젝트 소개

**ByO Target Platform**은  
🎯 **짧은 개발 기간** 안에서  
⚡ **빠른 협업과 안정적인 배포**를 목표로 하는 프로젝트입니다.

프론트엔드, 백엔드, AI가 유기적으로 연결되는  
**확장 가능한 플랫폼 구조**를 지향합니다.

---

## 🧑‍🤝‍🧑 팀 ByO

- 👨‍💻 Frontend: 강유비
- 🧠 AI: 권태성, 우서연, 이상화
- ⚙️ Backend: 김지훈, 강유비   

> 각 파트는 역할을 분리하되,  
> **PR 기반 협업**으로 코드 품질을 관리합니다.

---

## 🛠️ 기술 스택

### **Frontend**
- ⚛️ React
- 🎨 Tailwind CSS

### **Backend**
- 🐍 Python / Node.js
- 🌐 REST API

### **AI**
- 🤖 Machine Learning / Deep Learning
- 📊 Data Processing
